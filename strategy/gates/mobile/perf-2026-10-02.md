## Top 10 wins

1. **Shorten hydration gap**. Saves: 2407 ms average between FCP and interactive. Fix: Keep above-fold UI as server components, move interactivity to small client islands, and hydrate the splash and mega menu lazily.
2. **Reduce main-thread blocking (TBT)**. Saves: 703 ms average TBT at 4x CPU on 11 routes. Fix: Defer splash, animation and analytics scripts to requestIdleCallback, split long hydration with Suspense boundaries, avoid animating layout properties, and use CSS transform and opacity only.
3. **Preload or prioritise the LCP image**. Saves: about 300 to 700 ms LCP on 1 routes (/gallery). Fix: Add priority (fetchPriority high, preload) to the first above-the-fold next/image on those routes and make sure it is not wrapped in a client-only component or hidden behind the splash.
4. **Trim font payload**. Saves: 92.9 KB average font bytes. Fix: Subset to Latin, limit weights, use next/font with display swap and preload only the body weight.
5. **Fix lazy loading**. Saves: 0 eager images below the fold and 25 lazy images in the first viewport. Fix: Remove priority from images past the first screen; ensure only the LCP image is eager; give grid cards loading lazy.
6. **Bring route JS under 200 KB gzip**. Saves: 31.8 KB on 11 routes, about 163 ms download plus parse. Fix: Run next build with the bundle analyzer, lazy load the cart, wizard, splash, mega menu and consent code with next/dynamic after first paint, and drop unused libraries.
7. **Reduce request count**. Saves: 49 requests average. Fix: Lazy load below-fold images and sections, merge small chunks, avoid eager prefetch of every card link on slow networks.
8. **Shrink HTML payload**. Saves: 9 routes above 150 KB decoded HTML. Fix: Paginate or lazy render long grids, trim RSC payload props (pass ids not full objects) on listing pages.
9. **Serve images at the right width**. Saves: 260.3 KB across routes, about 121 ms per page. Fix: Tighten the sizes attribute on every next/image to the real CSS width (for example 50vw on two-column grids) and trim images.deviceSizes and imageSizes so the chosen srcset width is within 1.5x of CSS width times dpr.
10. **Add an offline fallback**. Saves: no white or browser error screen when data drops. Fix: Register a small service worker that caches the app shell, an /offline page and the last visited product pages; keep the order draft in localStorage (already mk.draft.v1).
